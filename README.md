# Site Bessa & Casagrande – Advocacia Especializada

Publicado em https://bessacasagrande.adv.br

- `index.html`, `css/`, `js/`: site principal
- `cartao/`: página do QR code do cartão de visita (bessacasagrande.adv.br/cartao)
- `contatos/`: contatos dos sócios para salvar no celular
- `_imagens/`: imagens em texto (base64); a publicação converte para `img/`

Cada alteração enviada para `main` é publicada automaticamente em cerca de 1 minuto.
